# 工具介绍
rakit是一款可以做linux系统状态检测的bash shell脚本，目前可以完成的功能：硬件信息检测、链接状态检测、ip通信性检测、配置ip、切换网络镜像源、切换时区等

# 开发背景
日常工作需要去检测或配置很多机器，虽然技术难度并不高，但是每次手动做一些重复的工作总是让我很抓狂，于2023年11月左右开始着手写的这个脚本，欢迎随时反馈一些遇到的问题。
